# SL21-01A2 — safe independent runner

The independent and reviewed lanes share one preparation and comparator path.
The driver inventories the exact pinned Git fixture blobs, determines the
historical eligibility policy, and prepares only selected primitive values before
calling the upstream `AdapterRunner#run_single` comparator. It does not call
`SpecLoader.load_all`, fixture generators, the fixture class registry, or a
fixture-supplied Ruby expression. There is no unsafe loader fallback. The
adapter rejects unexpected JSON-RPC callbacks; an explicit registry guard and
`Binding`/`Kernel` eval guards fail closed. The 56 additional standard-Drop
variants remain excluded.

Psych parses the pinned files using a restricted class loader. The known
non-JSON timestamps and YAML symbols are represented by inert metadata; no
fixture Date, Time, Range or Regexp object is instantiated. Unknown
timestamp shapes or tagged Ruby classes fail closed. The exact 100,000-byte
LongString admission is materialized by a bounded primitive implementation
after its individual source, shape and feature checks. Selected filesystems
contain only explicitly checked strings. Resource limits, parser modes and
raising/inline policies remain as before.

The two generated MethodDrop fixtures remain excluded and are not generated.
Their raw rows retain the original expressions and are labelled
`deferred-excluded-generator`. The legacy reviewed eligibility checksum contains
seeded metadata from the older loader. The reviewed profile projects those two
**excluded metadata fields only** from [source-bound historical evidence](../../Tools/LiquidSpecAdapter/ExcludedGeneratorEvidence.json)
for the checksum comparison, records the raw checksum and evidence hash, and
leaves the raw rows and comparator inputs unchanged. The evidence check verifies
that the retained historical receipt and matrix bind those values. No expression
is evaluated, and no excluded case is counted as an execution or a pass. The
seed is recorded as 15401; the excluded generator sequence is not replayed.

The fixture inventory lane compares all 5,112 identities and the 4,687/425
selection to the retained earlier matrix plus the 63 guarded admissions and
425-case historical review. Its materialization report keeps historical and
fresh evidence separate. The earlier 488-hold run has 1,976 missing render
requests, all after parse errors: 1,925 expected a parse error and 51 expected
another phase. No historical environment equivalence is inferred from those
missing requests. The 63 later admissions require fresh, clean-source Swift and
Ruby comparator evidence because their later historical wire traces are not
available in the retained earlier receipt. The full raw 425-hold historical
matrix is also unavailable locally; the documented five conflicts and aggregate
are comparison targets, not a substitute for identity-level raw history.

All qualification is source-bound and must be run on a clean commit using
`Scripts/ci.py`. Raw suite failures and the reviewed conflict decision remain
separate. An operational or missing observation cannot qualify as an expected
Liquid error, even if the unmodified upstream comparator reports a match.
