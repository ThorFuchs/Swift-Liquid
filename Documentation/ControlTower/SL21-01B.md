change the public Liquid runtime or remove the global Drop exclusion. The 56
proposed variants are the exact intersection of eleven targeted policies and the
historical 425-case hold register. Admission validates fixture identity and

parameters before creating a descriptor. A fixed case statement constructs only
the selected pinned Ruby reference objects; the existing adapter maps these to

forbidden. A descriptor is not a fixture-supplied protocol marker.

seeded outputs. Historical excluded cases emitted no render request, so those
historical wire inputs and templates cannot be directly compared; the pinned
fixture shape, historical output metadata, and separate exhaustive targeted
evidence support the reconstruction. This is not a replay of the complete
historical random sequence. The exhaustive 1,100 generated samples are distinct

The original 425-case disposition register and the earlier generator projection
are preserved. The reviewed profile validates each new admission and both engine
verdicts, then projects only those 56 records back to their retained historical
selection metadata for the existing checksum. This projection does not alter the
raw records or comparator. A raising ErrorDrop must actually raise a Liquid
render error; the inline case must produce the expected recovered diagnostic.

including three changed rendered outputs, predate the frozen baseline and remain
