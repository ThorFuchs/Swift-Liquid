# Community standards

Swift-Liquid welcomes contributors with different backgrounds and levels of
experience. Make technical discussion useful, specific and respectful.

- Review the code and evidence. Critique ideas without attacking people.
- Explain assumptions and provide reproducible examples where possible.
- Respect names, identities, accessibility needs and other people's time.
- Keep credentials, confidential templates and personal information private.
- Avoid harassment, discrimination, threats, impersonation and unwanted contact.

The maintainer may edit or remove harmful content, close disruptive discussions
or restrict participation using GitHub's moderation tools. Decisions should be
proportionate to the conduct and its effect on participants.

For a public moderation concern, open an issue linking the affected discussion
without repeating sensitive details. Use GitHub's report-abuse controls when a
report needs to remain private from other participants. Security vulnerabilities
have a separate [private reporting route](SECURITY.md).
