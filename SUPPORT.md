# Support

Use [GitHub Issues](https://github.com/ThorFuchs/Swift-Liquid/issues) for bugs,
questions, and focused feature proposals. Include the Swift version, operating
system, package revision, a minimal template and context, expected output, and
actual output or error. Remove confidential data first.

For security issues, follow [SECURITY.md](SECURITY.md). The project is maintained
by @ThorFuchs; no support response time or long-term maintenance window is promised.
